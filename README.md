# Infinite Pumpkin 交互动画

这是一个可直接在 VS Code 中打开的独立网页项目，包含完整的动画、交互空间、图片素材与背景音乐，不依赖在线框架。

## 打开方式

1. 双击 `infinite-pumpkin.code-workspace`，或在 VS Code 中选择“文件 → 从文件打开工作区”。
2. 如果 VS Code 提示安装推荐扩展，请安装 **Live Server**。
3. 在文件列表中右键 `index.html`，选择 **Open with Live Server**。
4. 浏览器将自动打开本地预览。

也可以直接双击 `index.html` 查看；使用 Live Server 时，图片与音频加载会更稳定。

## 项目文件

- `index.html`：网页入口
- `styles.css`：界面样式
- `animation.js`：开场动画与全部交互逻辑
- `assets/`：全景图片与背景音乐
